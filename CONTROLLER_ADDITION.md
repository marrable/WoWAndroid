### Task
to make an on screen controller that is optimised for wow gameplay; two mutually exclusive panes to allow the wow content to not be cluttered with the onscreen controls/keyboard
general idea

samsung zfold 8 (passport ration unfolded)

x-----------------------x
|                       |
| WoW FOREVER GAME VIEW |
|                       |
|-----------------------x <- grab-able handle to adjust ratio between game screen and controller
|LH Keyb/Con|RH Keyb/Con| <- toggle between touch screen xbox style controller and split qwerty keyboard
x-----------------------x

when the lower pane is in controller view, we probably need some hybrid of xbox controller + number row; 
this is because the wow forever controller support uses a basic layer chording system:
https://expcarry.com/wow-forever-controller-support
and this probably wont translate perfectly to purely touch screen. 
you'll need to investigate the ideal hybrid of x-box controller combined with regular number/map keys

in summary for the lower pane:
- view a; questing and general gameplay) optimised touch controls that are some hybrid of on-screen xbox controls and additional keys to support additional spells etc, given that the layer support for physical controllers mayb not be ideal in a pure touch environment
- view b; chat and social) a split qwerty keyboard with additional support for wow's social features like emote etc.
